# Я.Дом — Умный дом Яндекса на часах Amazfit

Мини-приложение для Zepp OS: комнаты, свет (яркость и цвет), розетки, климат,
датчики (протечка, температура, открытие), сценарии и ТВ-пульт через сценарии.
Работает через официальный API Умного дома Яндекса.

![QR](YaDom-QR-all.png)

## Установка

1. В приложении Zepp включите режим разработчика:
   Профиль → Настройки → О приложении → 7 раз тапнуть по логотипу.
2. Профиль → ваши часы → Режим разработчика → значок сканера.
3. Отсканируйте QR для своей модели часов (круг — круглый экран, квадрат — квадратный).

## Токен Яндекса

Верификацию Госуслуг можно просто закрыть.

1. Откройте https://oauth.yandex.ru → «Создать» → «Для авторизации пользователей» → «Перейти к созданию».
2. **Шаг 1 из 4.** Укажите название сервиса (например, `Zepp Yandex`), иконку (можно скачать иконку Zepp) и почту для связи → «Продолжить».
3. **Шаг 2 из 4.** Отметьте «Веб-сервисы», в поле Redirect URI вставьте `https://oauth.yandex.ru/verification_code`. Поле Suggest Hostname оставьте пустым → «Продолжить».
4. **Шаг 3 из 4.** В разделе «Основные» ничего не отмечайте. В поле «Дополнительные» введите по очереди и добавьте:
   - `iot:view` — Просмотр списка устройств умного дома
   - `iot:control` — Управление устройствами умного дома

   → «Продолжить».
5. **Шаг 4 из 4.** «Всё верно, создать приложение». Предупреждение «Сервис не верифицирован» для личного использования можно игнорировать.
6. На странице приложения скопируйте **ClientID**. Client secret не нужен.
7. Откройте ссылку, подставив свой ClientID:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID`

   Войдите под аккаунтом с умным домом → «Разрешить» → скопируйте токен (`y0_...`).
8. Zepp → часы → Приложения → «Я.Дом» → Настройки → вставьте токен.

## ТВ-пульт

Если телевизор добавлен как «свой пульт», создайте в «Доме с Алисой» сценарии:
«ТВ Вкл», «ТВ Выкл», «ТВ Громче», «ТВ Тише», «ТВ Звук», «ТВ Вверх», «ТВ Вниз»,
«ТВ Лево», «ТВ Право», «ТВ Ок», «ТВ Вход» — они появятся на экране пульта.

## Важно

- Часы выходят в интернет через телефон: Zepp должен быть запущен.
- Режим «Не беспокоить» на часах может блокировать связь.
- Подходит для часов на Zepp OS 3.0 и новее (см. подписи на карточках).
